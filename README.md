# Xoderony

面向 Unity 7 和 .NET 10 的基础库，提供集合、委托通道、通用扩展和对象池，不依赖 `UnityEngine`。

## 安装

在 Unity Package Manager 中选择 **Add package from git URL**，输入：

```text
https://github.com/Xoderony/Xoderony.git?path=unity/io.github.xoderony.core
```

## 兼容性

- Unity 7（`7000.0`）或更高版本
- .NET 10
