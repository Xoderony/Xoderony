# DI 容器设计

本文记录当前契约。公开用法见 [README](../../src/Xoderony.DependencyInjection/README.md)，调整决策见 [构建时集合方案](di-build-time-collections.md)。

## 目标与边界

面向 .NET 10，使用 BCL，支持类型、实例与工厂注册、父子容器、Key、构建时集合与反射注入。不支持开放泛型，仅接受完整闭合 Type，不按泛型定义分流或检查层级。

同一容器及共享父容器的体系由调用方保证串行使用。调用方保证先子后父释放，释放后不再使用。注册非法类型和配置冲突用参数异常报告，不使用断言；无法注册的服务类型在解析时按未注册处理，工厂及回调为空、工厂返回空对象等可能隐藏错误的情况必须拒绝。

## 注册与分组

- Register<T>()、Register(Type)、RegisterInstance(object)、RegisterFactory<T>(Func<IResolver,T>) 为入口。类型注册要求可构造类；工厂的声明 T 可以是接口或抽象类。
- 每条注册建立一个原始 Lazy，默认提供声明类型。As 替换默认暴露范围，AsSelf 追加自身，AsImplementedInterfaces 追加接口；重复 As 别名去重。同一注册所有别名共享实例。
- 同层 (声明类型, Key) 唯一：类型来源按实现类型，实例按实际类型，工厂按声明 T，跨来源统一检查。冲突在 Build 抛 ArgumentException，不执行构建回调。不执行工厂推断实际实现。
- 不同声明类型可以提供相同服务与 Key，按注册顺序组成服务组。一候选单个解析成功，多候选单个解析抛 InvalidOperationException，不求值任何候选；Build 不拒绝合法的多候选组。
- T[]（SZArray）、IEnumerable<T>、IReadOnlyList<T> 为保留服务类型。注册声明类型及 As 别名均拒绝，实例与工厂入口同样检查。具体 List<T> 不禁止，AsImplementedInterfaces 遇到保留接口报错。
- 每条注册只有一个 Key，所有别名共用。Key 为 int，默认 0，非零键不产生额外默认注册。枚举入口只接受 int 底层类型并无装箱转换；不同枚举类型按数值共享键，调用方协调编号。InjectKey 在分析阶段校验并转换枚举。

## 构建与解析

Build 用临时声明集合判重、临时服务组保存原始 Lazy 引用。每个非空组建立一个单个入口与三个集合入口，随后继承父层未覆盖的映射。映射建立阶段不提前分析、创建服务或求值集合；全部映射就绪后自动激活本层标记的注册。

RegistrationBuilder.AutoActivate() 幂等标记整条注册并返回自身。构建时临时列表保存本层标记注册的原始 Lazy，按注册顺序求值；依赖可能先创建。不按服务别名查找，因此支持多候选、键及工厂，不要求 AsSelf。类型沿用构造与注入，工厂沿用原有装配责任，已有实例不额外注入或接管释放。所有别名和集合继续共享原始缓存。激活列表不继承、不作为容器运行时状态保留。

运行时仅保留一张 (完整请求 Type, int Key) → Lazy<object> 注册字典；普通服务、闭合泛型和集合都查询一次。不再存在开放模板、闭合展开缓存或集合后备查找。字典未命中就是缺失；命中 Lazy 尚未求值时初始化，之后直接复用。多候选组的单个入口只缓存歧义异常，不额外访问候选。

Resolve 对缺失和歧义均抛 InvalidOperationException。TryResolve 仅对缺失返回 false，歧义和创建失败继续传播。IsRegistered 只看入口存在，多候选服务及其集合都为 true，不创建服务、不验证依赖。

## 自动集合

- 至少一条原始服务注册就生成 T[]、IEnumerable<T>、IReadOnlyList<T> 入口。删除 AsCollection，不存在独立集合成员声明。
- 只遍历原始服务组，不为新生成的集合再次生成集合。
- 三个入口共享集合 Lazy，首次求值按注册顺序取得原始实例，以 Array.AsReadOnly 包装私有数组。IEnumerable<T> 与 IReadOnlyList<T> 复用结果；T[] 每次复制数组，元素引用共享。
- 无服务组则无集合入口，不自动补空集合。外部不能直接注册保留类型来提供空集合；可选业务使用 TryResolve。
- 集合整体缓存失败，不重试；失败前已创建元素仍归原注册容器管理。

## 父子层与所有权

子层同服务类型与 Key 的组整组替换父层，单个和三个集合入口同时替换，不合并。普通与闭合泛型统一使用完整 Type，不存在跨层泛型族限制。兄弟容器独立；未覆盖别名继续引用父层原注册。

每层无键 IResolver 固定为自身，其三个自动集合入口也仅包含本层容器。生成本层完整映射后以 TryAdd 继承父层，防止留下父层旧集合。

类型与工厂结果由原注册容器创建、解析依赖并释放；继承引用不转移所有权。外部已有实例不自动注入或释放，工厂负责完整装配并移交结果所有权，不自动成员注入。工厂不能返回另一个容器服务、外部共享或借用对象来重复移交所有权。显式 Func<T> 后续调用产生的对象不自动归容器管理。

首次类型求值取得成员分析、分析构造函数，租借参数缓冲区、解析依赖、执行 ConstructorInvoker 与成员注入，成功后登记 IDisposable。参数缓冲区始终在 finally 中清空归还。工厂路径调用工厂并登记结果。使用 LazyThreadSafetyMode.None 缓存结果或失败，不包装异常、不重试。

## 注入规则

- 唯一的 [Inject] 构造函数优先，允许非公开；没有标记时要求唯一公开构造函数。
- [Inject] 标记实例字段、属性或方法；[InjectKey] 只指定服务键，不触发注入。
- 支持公开、非公开及继承成员。顺序为所有字段、所有属性、所有方法，各阶段先基类后派生类，同层成员不承诺顺序。
- 字段不能只读；属性必须有普通 setter，拒绝索引器和 init，包括 required init。
- 方法必须非泛型、非虚并返回 void；参数按值传递且可存入 object，不支持 byref、指针、byref-like 参数。静态成员不参与注入。
- 外部 Inject 仅分析成员，不要求构造函数合法；每次调用都重新注入。
- InjectionAnalyzer 集中构造选择、成员与参数分析。Dependency 只保存类型和 Key；MemberInjection 保存分析结果并执行注入，使用 required init 初始化。
- 参数依赖直接以数组保存，两个调用方分别填充参数缓冲区，不保留 ParameterBinding 或 ConstructorInjection 包装。

## 构建回调与释放

AddBuildCallback 在每次 Build 完成本层自动激活后、返回前按添加顺序执行，可显式 Resolve 预热其他服务；与标记 AutoActivate 的调用交错顺序无关。解析或注入本身不触发构建回调。回调与自动激活均不继承，子容器按自己的构建配置执行，父层依赖仍由父层创建并拥有。

激活失败直接传播异常，中止后续激活及全部回调；回调失败中止后续回调。保持原有失败行为，不增加异常处理分支：不自动释放已创建对象、不回滚副作用、不包装异常或重试。失败构建不返回容器；成员注入失败的对象尚未登记释放，Dispose 异常仍直接中断剩余释放。

容器按完成创建的逆序释放自身拥有的 IDisposable，别名不重复登记。无异步释放、自动子容器释放或重复使用保护状态。构建器变更不修改已经构建的映射；再次 Build 建立新的类型与工厂实例缓存，外部已有实例仍是原对象。

## 已决定不纳入

不提供开放泛型、AsCollection、Transient、Scoped、Lifetime 选项、ResolveAll、ResolutionException 包装、自动 Func<T>、init 注入、统一提前创建、Provider 框架或更多集合形式。

## 验证与成本

2026-09-14，49 项 Release 测试通过，零失败、零跳过。新增枚举/整数入口互通、默认零键、跨枚举同值、底层类型拒绝及带键注入验证。覆盖零/一/多候选、声明类型判重、Key、保留类型、闭合泛型、父子组替换与 IResolver、实例共享、集合不可修改、数组副本、失败缓存、循环与所有权。移除了只适用于旧开放泛型和显式成员契约的测试，用当前契约的可观察行为替代。

每个服务别名自动增加三个集合入口，Build 的映射数量与分配可能上升；一次查询不等于无构建成本。测量见 [构建时集合结果](../../benchmarks/results/di-build-time-collections.md)。历史开放泛型基准不代表当前显式闭合注册语义。
