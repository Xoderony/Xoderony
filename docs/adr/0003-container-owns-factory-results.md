# 工厂返回对象由容器管理

状态：已接受。替代 [工厂返回对象由外部管理](0002-container-factory-results-remain-externally-owned.md)。

## 决定

RegisterFactory<T> 被视为容器创建，仅创建方式由调用方定义。工厂使用注册所属容器的 IResolver，在首次解析时执行一次，负责完整装配并返回非空对象；容器缓存结果并负责 IDisposable 释放。工厂结果不自动成员注入，需要时由工厂显式调用 Inject。

普通类型也在首次解析时进行分析与创建，使两种来源具有相同的延迟创建及失败缓存时机。无所有权选择参数，不引入额外 Provider 层。

## 原因与代价

类型和工厂统一按注册位置确定实例归属，简化调用方的释放责任。作为代价，工厂不能返回外部共享对象或其他注册已经管理的对象，否则可能重复释放；已有对象应使用 RegisterInstance，别名应通过 As 配置。

工厂的任意创建逻辑无法静态检查依赖，错误在首次调用时暴露。容器不增加失败恢复或重试；异常由 Lazy 缓存。返回 Func<T> 只转交该委托本身，调用委托后来产生的对象由业务管理。
